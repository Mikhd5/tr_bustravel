TR BUS TRAVEL — оновлена адаптивна версія сайту

Перегляд локально:
1. Розпакуйте весь ZIP у папку.
2. Відкрийте index.html у браузері.
3. Не відокремлюйте папку assets та файли styles.css і script.js від index.html.

Склад сайту:
- index.html — структура сторінки;
- styles.css — адаптивний дизайн для комп’ютерів, планшетів і смартфонів, делікатні анімації Hero, маршруту, карток та кнопок;
- script.js — мобільне меню, вибір послуги, формування заявки у WhatsApp та плавна поява секцій під час прокручування;
- assets/ — фотографії, прозорий логотип TR BUS TRAVEL, favicon.
